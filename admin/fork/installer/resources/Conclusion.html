Nextcloud Fork установлен

Nextcloud Fork запускается автоматически после установки в сеансе текущего пользователя.

Если приложение не открылось, запустите его из Программы → RomanenkoApp → Nextcloud Fork.

Запускайте эту копию приложения. Папка сборки в Library/Caches не предназначена для постоянного запуска.

При запросе macOS разрешите использование расширения Nextcloud Fork в настройках системы. Настройки официального Nextcloud независимы.
