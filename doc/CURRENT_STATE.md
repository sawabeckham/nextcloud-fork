## Карта кода и устройство

Клиент C++/Qt/CMake. src/common — общие политики; src/libsync и src/csync — синхронизация; src/gui — интерфейс/аккаунты.
macOS-расширения — shell_integration/MacOSX/NextcloudIntegration; пакет NextcloudFileProviderKit рядом.
NEXTCLOUD_EXPERIMENTAL_HYBRID_SYNC разрешает обычные папки одновременно с File Provider. hybridsyncpaths исключает пересечения домашней папки/Library/CloudStorage.
NEXTCLOUD_FORK задаёт собственные бренд/ID site.manro.nextcloudfork/настройки/Keychain/ссылки. NEXTCLOUD.cmake, theme и admin/fork/make-fork-icons.swift — брендирование.
test/hybrid — профильные проверки политик. FORK.md — канонические подробности и история форка; upstream README описывает официальный клиент.
